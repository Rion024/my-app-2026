## 概要と特徴

### Memory Market とは

「Memory Market - 記憶査定所」は、あなたの大切な記憶の感情的価値を査定するユニークなWebアプリケーションです。市場における客観的な価格ではなく、あなたの心に残った記憶の重さを、独自の基準で量ります。

### 主な機能

- **記憶の入力** - 記憶の詳細を記入または音声で記録
- **AIによる整理** - 入力内容をAIが自動的に整理・精錬
- **感情査定** - 複数の指標から記憶を多角的に評価
- **査定書の発行** - 査定価格と査定等級を記載した査定書を発行
- **記憶保管庫** - 査定済みの記憶を保存・管理
- **再査定** - 記憶の新しい断片を追加して再度査定可能
- **音声入力対応** - ブラウザの音声認識機能で記憶を音声入力

> ⚠️ **重要：** このアプリケーションは、あなたの記憶を預かります。查定済みの記憶はブラウザのローカルストレージに自動保存されます。ブラウザのキャッシュをクリアするとデータが削除される可能性があります。

## クイックスタート

Memory Market を使い始めるための基本的な流れです：

1. **アプリケーションを開く**
   - ブラウザで Memory Market のページを開きます。

2. **査定窓口で記憶を入力**
   - 記憶の題名と詳細を入力します。他の項目は任意です。

3. **AIが記憶を整理**
   - 入力内容が自動的に整理されます。整理内容を確認します。

4. **査定を実行**
   - 整理された記憶に対して査定を実行します。

5. **査定結果を確認**
   - 査定書が表示され、査定価格と査定等級が記載されます。

6. **保管庫に保存**
   - 記憶を保管庫に保存して管理します。

> ⚠️ **注意：** 初回使用時には、ブラウザがマイクへのアクセスを要求する場合があります。音声入力を使用する場合は、許可してください。使用しない場合はキャンセルしても大丈夫です。

## 使用方法（詳細）

### 1. 査定窓口での記憶入力

Memory Market のホーム画面（「査定窓口」）では、以下の項目を入力できます：

| 項目 | 説明 | 必須 |
|------|------|------|
| 記憶の題名 | 記憶を表す短いタイトル。例：「夕立を避けた神社の軒下」 | 必須 |
| 記憶の記録 | 記憶の詳細を自由に記述します。当時の匂い、音、言葉、心の動きなど、記憶の断片をありのままに書いてください。 | 必須 |
| 記憶の年代 | 記憶がいつ頃のものかを記述。例：「十年前の夏」 | 任意 |
| 同席者 | その時一緒にいた人。例：「昔なじみの友人」 | 任意 |
| 主な感情 | 記憶に最も関連する感情を6つの選択肢から選択。 | 任意 |

#### 🎤 音声入力について

「声で記録する」ボタンをクリックすると、ブラウザの音声認識機能で記憶の詳細を音声で入力できます。執筆の手間を省きたい場合や、自由に話しながら記憶をまとめたい場合に便利です。

### 2. 記憶の整理と確認

「記録係に記憶を預ける」ボタンをクリックすると、入力された記憶がAIによって自動的に整理・精錬されます。

整理結果の画面では以下の操作ができます：

- **元の記録と整理済み記録を比較** - AIが正しく整理できたか確認できます
- **整理された記録で査定** - 整理済みバージョンで査定を実行（推奨）
- **整理された記録を修正** - 自動整理結果を手動で編集可能
- **元の記録のまま査定** - オリジナルのまま査定を実行
- **最初から書き直す** - 入力画面に戻って最初からやり直し

### 3. 査定の実行

記憶を確認したら、「査定を実行」ボタンをクリックして AIによる査定を開始します。査定には数秒かかる場合があります。

> 💡 **ヒント：** 査定中は画面に「記憶を読み取っています……」というローディング画面が表示されます。通信中のため、このまま待ってください。

### 4. 査定結果の確認

査定が完了すると、査定書が表示されます。査定書には以下の情報が記載されます：

- **査定価格** - 記憶の感情的価値（¥表記）
- **査定等級** - S / A / B / C の4段階
- **各種メトリクス** - 記憶を構成する5つの指標
- **査定士コメント** - 記憶への評価コメント
- **査定番号** - この査定の一意な識別番号

### 5. 記憶を保管庫に保存

査定結果に満足したら、「このまま保管庫へ保存する」ボタンをクリックして記憶を保管庫に保存します。

### 6. 記憶の断片を探す（再査定）

査定結果の画面から「記憶の断片を探す」ボタンをクリックすると、AIが生成した質問をもとに、まだ思い出していない記憶の欠片を探すことができます。

追加情報を入力すると、その情報が元の記憶に追加され、新たに再査定が実行されます。この場合、前回の査定価格との変化が表示されます。

> ⚠️ **注意：** 記憶の断片を追加して再査定すると、前回の査定結果は上書きされます。

## 感情カテゴリについて

Memory Market では、記憶に関連する感情を6つのカテゴリに分類しています。査定の精度を高めるため、できるだけ記憶に合った感情を選んでください。

| 感情カテゴリ | 説明 | 該当例 |
|-------------|------|--------|
| **郷愁・切なさ**<br/>Nostalgia | 過ぎ去った時間への思いや、二度と戻らない過去への懸念。 | 懐かしい場所の思い出、昔の友人との別れ、変わってしまった風景 |
| **喜び・幸福**<br/>Euphoria | 幸せを感じた瞬間や、喜びに満ち溢れた時間。 | 祝いの瞬間、愛する人との楽しい時間、成功の喜び |
| **悲しみ・喪失**<br/>Melancholy | 何かを失ったときの悲しみ、心が重くなるような出来事。 | 別れ、失敗、大切な人を失ったこと、失望した経験 |
| **怒り・葛藤**<br/>Friction | 不正義への怒りや、内なる葛藤の記憶。 | 不公平な扱いへの怒り、意見の対立、自分自身との戦い |
| **恐れ・トラウマ**<br/>Phobia | 不安や恐怖を感じた経験、心に残った恐怖の記憶。 | 危険に遭遇したこと、大きな失敗への恐怖、トラウマ的な経験 |
| **愛情・慈しみ**<br/>Agape | 誰かを愛する、慈しみの心に満ちた瞬間。 | 家族との絆、誰かのために何かをしたこと、深い信頼と思いやり |

> 💡 **ヒント：** 複数の感情が混在している記憶の場合は、最も強い感情を感じたカテゴリを選んでください。

## 査定メトリクス解説

Memory Market の査定結果には、記憶を5つの指標から分析したメトリクスが表示されます。各指標について説明します。

### 希少性 (Rarity)

人生においてどれほど再現不可能な体験であるかを示す指標です。0% から 100% の値で表示されます。

- **高い（70% 以上）** - 二度と起こりそうにない、ユニークな経験
- **中程度（40-70%）** - 滅多にない、しかし比較的可能性のある経験
- **低い（40% 未満）** - ありふれた、誰もが経験する可能性の高い経験

### 感情濃度 (Density)

その一瞬にどれほど濃厚な感情が注ぎ込まれていたかを示します。0% から 100% の値で表示されます。

- **高い（70% 以上）** - 非常に深い感情体験、心に刻まれた瞬間
- **中程度（40-70%）** - 中程度の感情的インパクト
- **低い（40% 未満）** - 軽微な感情体験、淡い記憶

### 再現困難度 (Difficult)

同様の体験を将来再現することがどれほど困難かを示します。0% から 100% の値で表示されます。

- **高い（70% 以上）** - 人生でもう二度と起こらない経験
- **中程度（40-70%）** - 再現には多くの条件が必要
- **低い（40% 未満）** - 比較的容易に再現可能な経験

### 未練係数 (Regret)

後悔、心のひっかかり、心残りを示す指標です。0 から 1 の数値で表示されます（1 が最大）。

- **高い（0.7 以上）** - 強い後悔や心残りがある
- **中程度（0.3-0.7）** - ある程度の未練がある
- **低い（0.3 未満）** - 後悔や未練がほとんどない

### 記憶の曖昧さ (Noise)

時間による忘却、美化、改変などで、記憶がどれほど曖昧になっているかを示します。0% から 100% の値で表示されます。

- **高い（70% 以上）** - 非常に曖昧で、正確性に欠ける記憶
- **中程度（40-70%）** - ある程度の曖昧さがある
- **低い（40% 未満）** - 比較的鮮明で正確な記憶

> 💡 **ヒント：** 査定結果のグラフを見ることで、自分の記憶の特性が一目で分かります。各メトリクスの値から、自分の記憶の特質を理解してみてください。

## 記憶保管庫の管理

### 記憶保管庫とは

「記憶保管庫」（「古い台帳」）は、査定を終えた記憶を保存・管理する場所です。ブラウザのローカルストレージに自動保存されます。

### 保管庫への操作

#### 保存された記憶を表示

ナビゲーションバーの「記憶保管庫」をクリックすると、保存済みの全ての記憶がリスト表示されます。各記憶カードには以下の情報が表示されます：

- 記憶の題名
- 査定日時
- 関連する感情
- 査定価格
- 査定等級

#### 記憶の詳細を確認

保管庫のリストで記憶カードをクリックすると、その記憶の査定書が再度表示されます。

#### 記憶を削除

各記憶カードの「記録を破棄する」ボタンをクリックすると、その記憶を保管庫から削除できます。

> ⚠️ **注意：** 削除した記憶は復元できません。削除前に確認ダイアログが表示されます。

#### 保管庫をクリア

保管庫の「保管庫を空にする」ボタンをクリックすると、保管庫に保存されている全ての記憶を一括削除できます。

> ⚠️ **注意：** この操作は取り消せません。確認ダイアログで再度確認されます。慎重に実行してください。

### データの永続性

保管庫のデータはブラウザのローカルストレージに保存されます。以下の場合、データが削除される可能性があります：

- ブラウザのキャッシュをクリアした場合
- ブラウザの設定で自動削除が有効になっている場合
- ブラウザのプライベート/シークレットモードを使用した場合（ウィンドウを閉じると削除）
- ブラウザのストレージ容量を超えた場合

> 💡 **ヒント：** 重要な査定記録がある場合は、定期的に査定書のスクリーンショットを撮るなど、別の方法でバックアップを取ることをお勧めします。

## よくある質問

### 音声入力がうまくいきません。どうしたら良いですか？

以下を確認してください：

- ブラウザにマイクへのアクセス許可がされているか確認
- マイクが正しく接続・認識されているか確認
- 周囲が静かか確認（ノイズが多いと認識しにくい）
- ゆっくり、はっきり話す
- 別のブラウザを試す（Chrome や Firefox が推奨）

### 査定価格はどうやって決まりますか？

査定価格は、記憶の以下の要素を分析して AI が算出します：

- 希少性（人生で二度と起こるか）
- 感情濃度（感情がどれほど濃いか）
- 再現困難度（将来再現できるか）
- 未練係数（後悔や心残り）
- 記憶の曖昧さ（忘却や改変）

これらをもとに、感情的な価値が算出されます。市場における客観的な価格ではなく、あくまで感情的価値です。

### 同じ記憶を何度も査定できますか？

はい。記憶の最後に記憶の断片を追加して再査定することで、新しい角度から記憶を評価できます。前回の査定結果との変化も表示されます。

### 査定結果を印刷できますか？

はい。ブラウザの印刷機能（Ctrl+P または Cmd+P）で査定書を印刷できます。印刷オプションで背景色も含めて印刷することをお勧めします。

### データはどこに保存されますか？安全ですか？

保管庫の記憶データはブラウザのローカルストレージに保存されます。あなたのコンピュータまたはデバイスにのみ保存され、サーバーに送信されることはありません。

ただし、査定時には記憶の内容を AI 解析のために送信します。プライバシーが気になる場合は、個人情報が含まれていない記憶から始めることをお勧めします。

### ブラウザを変更したらデータが見えなくなりました。どうしたら良いですか？

ローカルストレージはブラウザごとに独立しているため、異なるブラウザではデータにアクセスできません。同じブラウザで使用してください。

### オフラインで使用できますか？

アプリケーション自体はオフラインでも動作しますが、査定を実行するには AI のサーバーと通信する必要があるため、インターネット接続が必須です。

### 査定等級（S/A/B/C）の基準は？

査定等級は、複合的な分析に基づいて自動的に決定されます：

- **S 級** - 人生の中でも特に価値の高い記憶
- **A 級** - 高い感情的価値を持つ記憶
- **B 級** - 中程度の感情的価値を持つ記憶
- **C 級** - 低い感情的価値の記憶（ただし全く価値がないわけではない）

### 査定に何秒かかりますか？

通常、査定には 3-10 秒程度かかります。ネットワークの状態によって変動します。査定中は「記憶を読み取っています」というメッセージが表示されます。

## 使用のコツ

### より良い査定結果を得るために

#### 1. 記憶の詳細をできるだけ具体的に

「楽しかった」ではなく、「太陽が西に傾き、金色の光が林をつたって落ちてきた。友人は隣で笑っていた」のように、五感に訴える詳細を含めることで、AI がより正確に記憶を分析できます。

#### 2. 記憶の年代と同席者を記入

記憶の年代と同席者を記入することで、記憶の文脈がより明確になり、より精密な査定につながります。

#### 3. 正しい感情カテゴリを選ぶ

複数の感情が混在している場合でも、最も強い感情をカテゴリから選ぶことで、査定の精度が上がります。

#### 4. 記憶の整理結果を確認

AI による自動整理後、必ず内容を確認してください。必要に応じて編集し、意図した内容になっているか確認します。

#### 5. 記憶の断片を積極的に追加

「記憶の断片を探す」機能で追加情報を入力することで、記憶の解像度がより高まり、より正確な査定結果が得られます。

### 効果的な利用シーン

- **思い出の整理** - 人生の大切な瞬間を形にして記録したい時
- **感情の理解** - 自分の心に深く刻まれた経験を理解したい時
- **日記的な使用** - 定期的に心に残った出来事を記録していく
- **創作のインスピレーション** - 小説や詩など、創作活動の素材として
- **自己内省** - 人生を振り返り、自分自身をより深く知る

> 💡 **最後に：** Memory Market は、あなたの記憶と向き合う場所です。査定価格や査定等級も大切ですが、記憶を記録する過程そのものが、あなたの内面を理解する助けになることを願っています。
